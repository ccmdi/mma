**Import file** in the bottom bar adds locations from a file to the open map. You can also drag a JSON or CSV file onto the editor, or paste a list of links. Either way you get a preview first, with the new locations shown on the map in their own color.

To import whole maps instead, use <ChapterLink id="importing-existing">Import maps</ChapterLink> on the home screen.

## The import panel

- **Location count.** How many locations the file has.
- **Tags in file.** The tags it found.
- **Fields.** Every metadata field in the file, with how many locations have it. Untick a field to leave it out (remembered for next time).
- **Tag all imported locations.** Adds one or more tags to everything you import, so you can find the batch later.
- **Warnings.** Anything that went wrong reading the file.

Press **Import** to add them, or **Discard** to cancel.

## Formats

JSON and CSV are both detected automatically, and common column names (`lat`/`latitude`, `lng`/`lon`/`longitude`, `pano`/`panoId`) all work, so files from other tools usually just import.

The import doesn't check for locations you already have, so an overlapping file can leave <ChapterLink id="duplicates">duplicates</ChapterLink>.

<Note>

Imports of more than 500,000 locations are committed straight away and can't be undone (you can still revert them from the history). You're asked first.

</Note>
