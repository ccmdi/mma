Tags with a `/` in their name can be shown as folders: `Europe/France` goes under `Europe`. Turn it on with the tree button in the Tags header (or **View mode** in **Settings → Editing → Tags**).

## Using folders

- **Clicking a folder** selects every tag in it. <Kbd>Alt</Kbd>-click selects just the folder's own tag.
- **The arrow** opens and closes a folder. <Kbd>Ctrl</Kbd>-click it to open or close everything inside.
- **Folder color** is gray by default, or can match the first tag inside (**Folder color** in the same settings).
- **Short names.** **Truncate tag names to shortest unique path** hides the repeated part of long nested names.

## Organizing

- **Drag a tag onto a folder** to move it in. That renames it (`France` becomes `Europe/France`). Drop it on **Move to top level** to take it back out.
- **New folder** in the header makes a folder that isn't a tag itself.
- **The pencil** on a tag or folder edits only that one. To rename or recolor a folder and everything in it, right-click it and use **Rename folder** or **Recolor tags**.
- **Add alias** (right-click a tag) shows the tag in a second place in the tree too.

<Note>

**Remove from all** on a folder takes off every tag inside it. **Remove this tag only** leaves the tags inside alone.

</Note>
