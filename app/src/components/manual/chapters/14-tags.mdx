Tags are colored on/off labels you attach to locations. They are boolean: a location either carries a tag or it does not.

## Creating and assigning

1. Create a tag from the Tags section; it gets a name and a color.
2. Assign tags while editing a location, using the tag bar at the bottom of the editor (type to add, click suggestions, X to remove).
3. **Quicktags.** While editing a location, number keys <Kbd>1</Kbd> through <Kbd>9</Kbd> toggle the first nine visible tags by position. These keys are rebindable. Quicktags and autocomplete suggestions follow your chosen tag sort order (name, count, or manual).
4. **Per-map hotkeys.** You can assign a dedicated hotkey to any tag from its edit dialog. Pressing the key while a location is open applies or removes the tag. These bindings are stored per-map, not globally. See <ChapterLink id="controls-hotkeys" />.
5. Click a tag pill in the Tags section to select every location carrying it; shift-click to extend a range.

## Colors, order, and visibility

- **Color.** Each tag has a color used for its markers, set with a color picker. To recolor several at once, select them, right-click one and choose **Recolor tags**.
- **Order & sort.** Drag tags to reorder, or sort by name or count.
- **Visibility.** Hide a tag to declutter the map. A tag automatically becomes hidden when no location carries it.
- **Suggestion limit.** Cap how many tags appear in autocomplete and quicktag lists in **Settings → Editing → Tags → Suggestions shown**.
- **Spacing.** **Tag gap** controls how tightly tag pills pack together, useful on maps with hundreds of tags.

## Tree grouping

With **View mode** set to **tree** (**Settings → Editing → Tags**), tags whose names contain `/` are grouped hierarchically, e.g. `Europe/France` nests under `Europe`. Parents show partial-selection indicators and inherit color. Two options refine it: **Folder color** (inherit from the first child, or a fixed color) and **Truncate tag names to shortest unique path**, which drops the redundant prefix from deeply nested names.

- **Virtual folders.** Create folder nodes that don't correspond to a real tag. They get their own color and name, edited from the folder's pencil button. The pencil on any tag or folder edits only that node; to rename a folder with everything in it, or recolor every tag inside, right-click it and choose **Rename folder** or **Recolor tags**.
- **Tag aliases.** Place a tag at a second folder path via the **Add alias** item in a tag's context menu. The alias appears in the tree at the chosen path alongside the original.

## Tag tools

- **Apply metadata as tags.** Pick a metadata field and <App /> creates one tag per distinct value, assigning each location the tag for its value (command palette). For example, applying **countryCode** turns a map into per-country tags in one step. Date and month fields offer a grouping choice (year, year-month, exact day, month of year, or hour of day), with an optional **Location timezone** checkbox; number fields can be bucketed by a fixed width (e.g. altitude in 500m bands). The same partition options are available in the Gradient plugin.
- **Find and replace in tag names.** Bulk-rename across tags (command palette).
- **Download tag counts as CSV.** Export per-tag counts (command palette).
- **Remove tags.** Right-click a tag and choose **Remove from all** to delete it from every location. On a folder this takes every tag under it (**Remove this tag only** keeps them); on a tag that is part of your current tag selection it takes every selected tag.
- **Rename in selection.** Right-click a tag to move only the selected locations to another name, splitting the tag. Naming an existing tag merges into it; with several tags selected, they all merge into that one name.
- **Assign document links.** Point tags at headings in a Google Doc, so the relevant section shows up beside the map. See <ChapterLink id="doclinks" />.
