This chapter is about the basic flow for most users. It will be mostly familiar coming from the web version.

<Note>

This is a work in progress and data loss can _rarely_ happen. Keep backups. The recommended backup is <ChapterLink id="bulk-backup">**Export all maps**</ChapterLink> on the home screen.

</Note>

## Your first map

1. **<ChapterLink id="map-list">Make a map.</ChapterLink>** On the home screen, type a name in the search box and press <Kbd>Enter</Kbd>.
2. **<ChapterLink id="adding-locations">Add a location.</ChapterLink>** Click the map near Street View coverage. The location snaps to the nearest panorama and opens.
3. **<ChapterLink id="location-editor">Edit it.</ChapterLink>** Look around until you have the view you want, then press **Save** (<Kbd>Enter</Kbd>).
4. **<ChapterLink id="tags">Tag it.</ChapterLink>** Type a tag name in the bar under the panorama. New tags are created as you type them.
5. **<ChapterLink id="selections">Select it.</ChapterLink>** Click a tag in the sidebar to select every location with that tag. Selections are what you review, export, and run bulk operations on.
6. **<ChapterLink id="commits">Commit.</ChapterLink>** Your edits are saved automatically, but a commit (bottom bar, or <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd>) is a version of the map you can go back to.

If your maps are on map-making.app, you can <ChapterLink id="importing-existing">import them all at once</ChapterLink>.

Everything is stored in the app's <ChapterLink id="data-folder">data folder</ChapterLink> on your computer.
