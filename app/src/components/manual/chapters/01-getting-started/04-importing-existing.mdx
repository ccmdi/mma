export const title = "Importing your existing maps";

If you use [`map-making.app`](https://map-making.app), you can bring all your maps across at once. On the website, use **Download data** to get a ZIP of your maps. Then:

1. On the <App /> home screen, click **Import maps** (bottom-right).
2. Choose the ZIP, or one or more JSON files.
3. The preview lists each map with its location count, tag count, and folder.
4. Pick which maps to import with **All**, **None**, or **New only**, or tick them one by one. Maps with the same name and location count as one you already have are marked **duplicate** and unticked, so importing the same ZIP twice doesn't double up.
5. Press **Import N maps**. Progress shows in the bottom-right.

Nothing is imported until you press the button.

**Export all maps**, next to it, does the reverse: one ZIP of every map. It's also the <ChapterLink id="bulk-backup">recommended backup</ChapterLink>.
