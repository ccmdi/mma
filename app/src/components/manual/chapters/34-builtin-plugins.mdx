The Core tab includes:

- **Map generator.** Generates Street View locations from coverage inside regions you draw, with extensive quality filters (camera generation, date ranges, official vs unofficial, minimum spacing, and more). It can follow linked panoramas to spread coverage. A **Sampling** control chooses how candidate points are distributed: **Random**, **Uniform** (Poisson disk), **Grid** (a honeycomb of search points that covers the whole region once, in random order), **Coverage** (blue-line sampling), or **Grow** (kernel-based expansion). Additional options include searching within panorama descriptions, filtering by number of links, keeping only panoramas that sit on a bend of a minimum angle, setting a fixed output zoom level, and adjusting the generation speed. Settings changes apply mid-run. An optional search-coverage overlay visualizes where the generator has searched. The generator session persists across view switches, so you can leave and return without losing progress.
- **Vali.** Generates locations from pre-built coverage data rather than by probing Street View, so it is much faster than the generator where that data exists. Progress streams as it runs. Coverage data is fetched automatically the first time a country is needed; the **download** button in the panel header does it on demand for a country, a continent, or everything at once, and can force a full redownload. When you open the panel it quietly checks whether the data you already downloaded has been superseded, marks the download button if so, and offers to update just those countries.
- **Distribution.** A live bar chart of how your locations are spread across countries, with flags and counts. It resolves countries offline from coordinates, so it works with zero enrichment; a **Coordinates** / **Metadata** toggle switches between coordinate-based counts and your enriched `countryCode` field when one is present.
- **Disambiguate.** Ranks metadata fields by how strongly they separate your active selections, helping you find what distinguishes one group from another.
- **Gradient.** Colors locations by a field value using gradient buckets. Supports the same date/number partition modes as **Apply metadata as tags**. A scope selector lets you color only the current selection, with bucket boundaries computed from the subset.
- **Pivot Table.** Cross-tabulates selections against location metadata.
- **map-making.app sync** and **GeoGuessr.** Link the open map to a remote map and keep the two in step. See below.

## Syncing with a remote map

Both sync plugins work the same way. Sign in, search the remote account for a map, and **Link this map** to pair it with the one you have open. On the first sync you choose how the two sides are reconciled:

- **Merge.** Keep everything from both sides. Never deletes.
- **Mirror from remote.** Make the local map match the remote one.
- **Mirror from local.** Make the remote map match yours.

After that it is a plain three-way merge: **Sync now** pushes your changes, pulls theirs, and lists anything it could not decide (both sides added, both sides edited, deleted on one side and edited on the other) for you to resolve. **Sync continuously while this map is open** does it in the background as you edit.

Both are marked **experimental** - link a map you have a backup of before trusting them with real work.
